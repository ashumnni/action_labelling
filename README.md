# Dual-Mode GPT-4o Action Engine

A production-grade Temporal Action Localization (TAL) and labeling engine powered by GPT-4o Vision. This system generates both high-fidelity descriptive human activity labels and concise, imperative robot command contexts for long, untrimmed videos.

## 🚀 Key Features

- **Dual-Mode Labeling**: 
  - **Descriptive Pass**: Generates detailed 10-12 word activity summaries.
  - **Robot TAL Pass**: Generates 6-8 word imperative commands for robot control.
- **100% Temporal Coverage**: Strict enforcement of contiguous segments with no gaps in timeline.
- **Multimodal Dataset Generation**: Automatic screenshot extraction for visual training sets.
- **Real-Time Visualization HUD**: Dynamic overlay of action labels, timestamps, and confidence scores.
- **Adaptive Refinement**: Multi-stage processing with coarse-to-fine temporal boundary detection.

   ```env
   OPENAI_API_KEY=your_actual_key_here
   ```

## 💻 Usage

### 1. Generate Action Labels
Run the labeling script on your video. You can choose between `descriptive` (default) and `tal` (robot command) formats.

```bash
# Generate Descriptive Labels
python gpt_labeler.py --video video.mov --format descriptive --output results_descriptive.json

# Generate Robot Command Context (TAL)
python gpt_labeler.py --video video.mov --format tal --output results_tal.json
```

**Key Arguments**:
- `--video`: Path to input video file.
- `--format`: Labeling mode (`descriptive` or `tal`).
- `--mode`: Processing strategy (`standard` or `adaptive` for high-precision boundaries).
- `--workers`: Number of parallel threads for GPT API calls (default: 4).

### 2. Visualize Results
Overlay the generated labels onto the video for verification and presentation.

```bash
python visualizer.py --video video.mov --master results_tal.json --output video_labeled.mp4
```

## 📊 Output Data Structures

### Master Ledger (`master_results.json`)
The system maintains a centralized JSON ledger mapping video filenames to their latest labeling segments, facilitating easy integration into training pipelines.

### Screenshot Dataset
Screenshots used for labeling are automatically saved in `dataset/screenshots/<video_name>/`, creating a structured image-label dataset.

## 🧬 Legacy Model (MultiLSTM)
The original MultiLSTM PyTorch implementation is available for training local models using the high-quality synthetic labels generated by this GPT-powered system.
